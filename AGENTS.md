# Working on the interface

Read [DESIGN.md](DESIGN.md) before changing a screen, a worker animation, or user-facing application states. The guide includes screenshots of the native app, component and layout rules, and a worked example for extending a workflow.

Use [PRODUCT.md](PRODUCT.md) for submission and privacy behavior. The interactive [Application Crew prototype](docs/design-drafts/crew/index.html) lets you explore the original design with fictional jobs. Production views live in `gui/` and read their state from the application engine.
