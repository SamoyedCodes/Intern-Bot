# Fictional NUS Data Science / Computer Science Student Resume

This is a **fictional example profile** filled into the *Data Science & Tech Resume Template* by Timmy Chan:
https://github.com/TimmyChan/data-science-tech-resume-template

All names, contact details, work placements, metrics, projects and activities are illustrative and **must not be presented as real personal achievements**. The NUS programme description, Year 2 status, second major in Computer Science and GPA of 4.55/5.00 reflect the brief.

## Files
- `resume.tex`: main LaTeX source, including header placeholders.
- `sections/`: editable LaTeX sections (profile, education, skills, experience and activities).
- `_header.tex` and `TLCresume.sty`: original header and styling.
- `resume.pdf`: preview compiled from the source.
- `LICENSE.txt`: the original licence.

## Editing
Open the project in Overleaf or compile locally using `pdflatex resume.tex` (run twice if needed). Replace the fictional material and sample links before using the resume for any application.
